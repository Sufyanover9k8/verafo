These files live in the project root

The site currently links to its assets with root-relative paths, and they resolve correctly as things stand. Nothing here needs changing for the site to work.

If you would like a tidier root later, create an assets folder, move these three files into it, and rename them to drop the spaces:

  • Verafo logo 1.0.jpeg → assets/verafo-mark.jpeg
  • Verafo logo 2.0.jpeg → assets/verafo-wordmark.jpeg
  • image.png → assets/dashboard.png

Then, in all seven HTML files, replace Verafo%20logo%201.0.jpeg with assets/verafo-mark.jpeg and image.png with assets/dashboard.png. Note that Verafo logo 2.0.jpeg is not referenced by the site at all: the logo in the header is drawn as inline SVG so it stays crisp, which also means the mark works on light and dark backgrounds.
